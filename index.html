    About this demonstrator

    IntelliTwin replays a morning peak simulated with Eclipse SUMO on the OpenStreetMap road network of Abu Dhabi city. The roads are real; the traffic is simulated from assumptions, not observed. No traffic counts are public for Abu Dhabi, so the model is not calibrated or validated.

    It is an independent demonstrator, not an official model of any UAE authority, and must not be used for planning, investment, operational, legal or safety decisions.

    Sources, method, file formats and limits are in the docs folder.

    Roads © OpenStreetMap contributors (ODbL). Base map tiles © OpenStreetMap contributors. Buildings: Microsoft Global ML Building Footprints. Bus timetable: Integrated Transport Centre GTFS. Software: Eclipse SUMO, deck.gl, MapLibre GL JS.
