                            What is built

                            Validation

                            Not calibrated

                            No traffic counts or journey times are connected, so the model has not been checked against measured traffic. Connecting counts is the first step to a decision-grade model; see docs/limitations.md.

                            About this demonstrator

                            IntelliTwin shows traffic on the OpenStreetMap road network of Abu Dhabi city. The roads are real. The traffic is simulated with Eclipse SUMO from assumed demand, and the live and historical views are a synthetic feed built from those simulated states. Accidents, fines, devices and camera views are illustrative.

                            It is an independent demonstrator, not an official model of any UAE authority, and must not be used for planning, investment, operational, legal or safety decisions.

                            Sources, method, configuration and limits are in the docs folder.

                            Roads © OpenStreetMap contributors (ODbL). Base map: OpenStreetMap data, vector tiles by OpenFreeMap. Buildings: Microsoft Global ML Building Footprints. Buses: synthetic example network. Software: Eclipse SUMO, deck.gl, MapLibre GL JS.
