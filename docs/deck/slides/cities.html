Plug-and-play cities

A new city is a folder, not a project

Abu Dhabi, Dubai and Riyadh run from the same product.

A city pack holds roads, districts, limits, fines, currency and plate format.

Add a city: write the config, build the network, restart.

Riyadh: about 4,000 road segments, no code changes
This is Riyadh, loaded in about two seconds from its city pack. Road geometry comes from OpenStreetMap. Fine schedules in the packs are illustrative and would be replaced by the customer's official schedule.
